Note

옵시디언 필수급 플러그인 CMDS-Eagle을 제대로 사용하기 위한 Cloudflare R2 세팅법.
한번 설정하면 그 다음부터는 아주아주아주아주 편하게 스크린샷 복붙을 무지성으로 할 수 있다.
Achmage-slides-ultra와 연계하면 더욱 강력해진다.

CMDS-Eagle 플러그인용 Cloudflare R2 설정하기

1. Cloudflare Dashboard 아이디 만들기

  • 먼저 https://dash.cloudflare.com/login 에 접속한다.

    • Sign up을 눌러서 ID를 만든다

  • 유효한 이메일로 아이디를 만든다음 로그인한다.

    • 그러면 아래처럼 화면이 나온다.

2. Cloudflare Worker 만들기

  • 가운데 검색창 메뉴에서 create worker 라고 검색해서 메뉴를 클릭한다.

  • 그러면 아래처럼 이메일 인증이 나온다 인증해주자

  • 그러면 아래 화면이 나온다

    • 아래 화면에서 두번째 줄에 start with Hello World! 를 누른다.

  • 그러면 아래와 같이 Worker name 에서 텍스트를 지우고 obsidian-eagle-uploader로 대충 이름을 짓는다

  • 맨 아래에 deploy를 누르면 아래와 같은 화면이 나온다. 우측 상단에 Edit Code를 클릭 한다

  • 왼쪽 아래 Hello World 부분 텍스트를 싹 다 지운다

  • 그리고 나서 아래 텍스트를 복붙한다:
    • 복붙해서 교체한다음 반드시 우측 상단의 deploy 버튼을 누른다
export default {
  async fetch(request, env) {
    const url = new URL(request.url);

    const corsHeaders = {
      "Access-Control-Allow-Origin": "app://obsidian.md",
      "Access-Control-Allow-Methods": "GET, POST, OPTIONS",
      "Access-Control-Allow-Headers": "authorization, content-type, x-api-key",
      "Access-Control-Max-Age": "86400",
    };

    function json(data, status = 200) {
      return new Response(JSON.stringify(data), {
        status,
        headers: {
          ...corsHeaders,
          "Content-Type": "application/json",
        },
      });
    }

    function getProvidedKey() {
      const authHeader = request.headers.get("authorization");
      const xApiKey = request.headers.get("x-api-key");

      if (authHeader) {
        return authHeader.startsWith("Bearer ")
          ? authHeader.slice(7)
          : authHeader;
      }

      if (xApiKey) {
        return xApiKey;
      }

      return null;
    }

    function isAuthorized() {
      const providedKey = getProvidedKey();
      return Boolean(providedKey && providedKey === env.UPLOAD_API_KEY);
    }

    // Obsidian/Electron이 실제 POST 전에 보내는 CORS 사전 확인 요청
    if (request.method === "OPTIONS") {
      return new Response(null, {
        status: 204,
        headers: corsHeaders,
      });
    }

    // 연결 확인용. 브라우저에서 그냥 열면 Unauthorized가 나올 수 있다.
    if (url.pathname === "/health") {
      if (!isAuthorized()) {
        return json({ success: false, message: "Unauthorized" }, 401);
      }

      return json({
        success: true,
        message: "OK",
      });
    }

    // CMDS Eagle은 이 경로로 업로드한다.
    if (url.pathname !== "/upload") {
      return json({
        success: false,
        message: "Not Found",
        hint: "Use POST /upload",
      }, 404);
    }

    if (request.method !== "POST") {
      return json({
        success: false,
        message: "Method Not Allowed",
        hint: "Use POST /upload",
      }, 405);
    }

    if (!isAuthorized()) {
      return json({
        success: false,
        message: "Unauthorized",
      }, 401);
    }

    let formData;

    try {
      formData = await request.formData();
    } catch (error) {
      return json({
        success: false,
        message: "Invalid form data",
        error: String(error),
      }, 400);
    }

    const file = formData.get("file");
    const originalFilename =
      formData.get("filename") ||
      (file && typeof file !== "string" && file.name) ||
      "upload.bin";

    const contentType =
      formData.get("content_type") ||
      (file && typeof file !== "string" && file.type) ||
      "application/octet-stream";

    if (!file || typeof file === "string") {
      return json({
        success: false,
        message: "No file uploaded",
      }, 400);
    }

    const filenameText = String(originalFilename);
    const cleanExt = filenameText.includes(".")
      ? filenameText.split(".").pop().replace(/[^a-zA-Z0-9]/g, "").toLowerCase()
      : "";

    const ext = cleanExt || "bin";

    // R2 안에 저장될 파일 경로
    const key = `images/${Date.now()}-${crypto.randomUUID()}.${ext}`;

    await env.MY_BUCKET.put(key, file.stream(), {
      httpMetadata: {
        contentType: String(contentType),
      },
    });

    const publicUrl = `${env.PUBLIC_BASE_URL}/${key}`;

    return json({
      success: true,
      key,
      filename: filenameText,
      url: publicUrl,
      publicUrl,
    });
  },
};

3. R2 Storage 및 Bucket 만들기

  • 우측 상단에서 R2 라고 검색하면 R2 Object Storage > Overview 라는 항목이 나온다. 클릭해보자

  • 그러면 아래와 같이 결재 옵션이 나오는데 쫄지 말고 Add R2 Subscription to my account 를 누른다

  • 아래와 같은 화면이 나오는데 설정하고 이미지 업로딩용으로만 쓰면 돈 하나도 안나가니까 쫄지 말고 카드 내거 아무거나 입력하자.

  • 그러면 아래처럼 화면이 나올텐데 Create bucket을 클릭하자

  • bucket name을 대충 아무거나 지은다음 : obsidian-images 이런식으로 맨 밑에 create bucket을 누른다

  • Settings 에 들어가서 Public Development URL 옆에 Enable을 켠다

  • allow를 입력하고 누른다

  • 그러면 주소가 생기는데 메모장에 따로 복붙해놓자 (Public URL)

4. Bucket & Binding 설정하기

  • 이제 다시 왼쪽 설정창에서 Workers라고 검색해서 Workers & Pages 로 들어가자

  • Workers & Pages에서 위에서 아래와 같이 Worker name 에서 텍스트를 지우고 obsidian-eagle-uploader로 대충 이름을 지었던 그 이름을 검색해서 들어간다

  • Bindings가 비어있을 것이다. Add binding 을 누른다

  • Binding을 다시 누른다음

  • R2 Bucket을 선택하고 Add binding 클릭

  • Variable name에는 MY_BUCKET 이라고 입력하고,

    • 밑에 R2 Bucket은 바로 전단계에서 만든 버켓이 아마 골라질 것이다
    • 선택하고 밑에 Deploy를 누르면 된다

5. Worker URL 메모장에 복붙하기

  • 다시 Workers & Pages 에서 Overview 로 돌아오면
    • 아래 스크린샷처럼 XXXX.아이디-###.workers.dev 같이 끝에 .dev 로 끝나는 인터넷 주소가 있다
    • 그걸 메모장에 따로 복붙해놓자 (Worker URL)

6. Secret & Key 설정하기

  • 그 상태에서 다시 Settings 로 다시 간다
    • 그러면 Variables and secrets 항목이 비어있을 것이다.
    • Add를 누른다.

  • Variables and secrets 창이 뜬다
    • Type 을 Secret 으로 고르기
    • Variable name 을 UPLOAD_API_KEY 처럼 입력
    • Value에 내가 입력하고 싶은 비밀번호 아무거나 입력하고 메모장에 따로 저장
  • 셋 다 입력하고 Deploy를 누른다.

  • 마찬가지로 한번 더 Add 를 눌러서
    • Type 을 Text 로 고르기
    • Variable name을 PUBLIC_BASE_URL 로 입력
    • value에 주소를 위에 3단계에서 R2 Storge & Bucket에서 만들고 메모장에 복붙했던 주소를 그대로 입력한다.
  • 다 입력하고 Deploy를 누른다.

  • (참고 RECAP) 그러면 주소가 생기는데 메모장에 따로 복붙해놓자 (Public URL)

6. CMDS-Eagle 플러그인에 Cloudflare R2 값 입력하기

  • 이제 세팅이 다되었으면 메모장에 아래의 세가지가 있다:

  • 옵시디언 설정 - 커뮤니티 플러그인 - 탐색 메뉴에 들어가서 CMDS 라고 검색하면 아래처럼 CMDS Eagle 이라는 앱이 나오는데 설치한다

  • CMDS Eagle 설정창에서 밑에 Cloud Storage Provider를 Cloudflare R2 로 바꾼다음,

  • Worker URL, API Key, Public URL에 각각 메모장에 복붙해놨던 값들을 입력하자

2) 지금의 나와 어떻게 연결되는가?

DIKM: Y-Axis

DIKM의 “삶과 연결되는 지식” 관점에서, 내 루틴/관계/연구/창작과 연결 고리 만들기

  • 범정부 오피스에서 HanMark 1.0까지, 한글 자동화 옵시디언 플러그인을 향한 9개월 283간의 분투 기록 도 참조. HanMark + 스마트 컴포저 (Achmage 수정본) + Achmage-slides-ultra + CMDS-Eagle (Cloudflare R2 설정) 이야말로 왕초보를 위한 옵시디언 입문 마스터 패키지의 완성본이라고 할 수 있다.
    • 특히 이런 스크린샷 첨부하는 CMDS-Eagle (Cloudflare R2) 설정을 해놓으면, 굳이 HTML Slide가 아니라 PPTX로 만들고 싶은 경우, 해당 마크다운을 클로드 코드나 코덱스 등에 첨부한 뒤 스크린샷 링크들 크기를 감안해서 PPT로 만들어줘 같이 시켜버리면 깔끔하게 나온다.
