Kaggle 가입 및 무료 GPU 활용

가입 조건과 무료 GPU 사양

  • Kaggle 가입 필요: AI 이미지 및 영상 제작을 위해 Kaggle에 가입해야 한다.
  • 무료 GPU 제공: Kaggle은 일주일에 30시간 무료 GPU를 대여해준다.
    • 가입 시 휴대폰 인증이 필요하며, 인증 완료 시 16GB GPU 두 장을 무료로 사용할 수 있다.
  • "절대 돈 내지 마라": 이 규칙을 강조한다.

Krea 2를 이용한 AI 이미지 생성

Krea 2 모델과 실행 환경 준비

  • Krea 2 모델 소개: 오픈소스 모델 중 성능이 괜찮은 Krea 2를 사용하여 이미지를 생성하는 방법을 설명한다.
  • 노트북 활용 및 실행 환경 준비: 직접 노트북을 만드는 대신, 미리 준비된 노트북 링크를 활용한다.
    • 노트북 링크를 복사(Copy & Edit)하여 사용한다.
    • 총 5단계로 구성되어 있으며, 첫 단계는 실행 환경 준비이다.
    • 세션 옵션에서 GPU를 반드시 켜야 한다.
    • 인터넷 연결 상태를 확인한다.
    • 1단계 셀을 실행하면 환경 준비가 완료된다.

이미지 생성 2~5단계 실행

  • 2단계 · AI 그림 생성 프로그램 설치: 2단계에서는 AI 그림을 그려주는 프로그램을 설치한다.
    • 셀을 실행하면 약 3분 후 설치가 완료된다.
  • 3단계 · AI 모델 다운로드: 3단계에서는 그림을 그리는 AI 모델을 다운로드한다.
    • 셀을 실행하면 약 1분 만에 모델 다운로드가 완료된다.
  • 4단계 · 정상 실행 확인: 4단계는 매우 빠르게 진행되며, 한 줄이 나타나면 정상 실행된 것이다.
  • 5단계 · 프로그램 실행 및 이미지 생성: 5단계에서는 프로그램을 실행하며, 약 1분 후 이미지 생성을 위한 링크가 나타난다.
    • 생성된 화면에서 프롬프트 입력, 이미지 개수, 해상도, 스타일 등을 선택하여 이미지를 만들 수 있다.
    • 프롬프트에 맞는 이미지가 생성되는 것을 확인할 수 있다.
    • 무료 GPU 사용 시간은 세션 옵션에 표시되며, 이미지 생성 시 시간이 소모된다.

세션 종료의 중요성

스톱 세션

GPU 사용을 중단하려면 반드시 '스톱 세션' 버튼을 눌러야 한다.

LTX 2.3을 이용한 한국어 대사 영상 생성

LTX 2.3 모델과 노트북 실행 준비

  • LTX 2.3 모델 소개: 생성한 이미지들로 한국어 대사가 가능한 LTX 2.3 모델을 사용하여 영상을 만든다.
    • 이 모델은 오픈소스 중 한국어 대사가 가장 자연스러운 모델로 평가된다.
  • 노트북 복사 및 실행 환경 설정: 영상 제작을 위한 노트북 링크를 복사하여 사용한다.
    • 이미지 생성과 마찬가지로 5단계로 구성되어 있으며, 영상 모델이라 시간이 더 소요된다.
    • 단계별 또는 한꺼번에 실행할 수 있다.
    • 실행 전 세션 옵션에서 GPU 선택 및 인터넷 연결을 확인해야 한다.
    • '런 5'를 눌러 실행한다.
  • 단계별 실행 및 완료: 1단계부터 4단계까지 순차적으로 실행되며, 각 단계 완료 메시지가 표시된다.
    • 마지막 단계에서 영상 생성을 위한 링크가 나타난다.

영상 생성 화면 및 옵션

  • 입력 방식: 링크를 클릭하면 영상 생성 화면이 나타나며, 텍스트만 입력하거나 첫 장면, 시작 이미지와 끝 이미지를 넣어 영상을 만들 수 있다.
    • 예시로 Krea 2로 만든 아이와 로봇 이미지를 사용한다.
  • 프롬프트 언어: 프롬프트는 기본적으로 영어로 입력하고, 한국어 대사는 한국어로 작성한다.
  • 길이와 화질: 영상 길이와 화질을 선택할 수 있으며, 화질이 높거나 길이가 길수록 시간이 더 걸린다.
    • 처음에는 480p로 시작하여, 결과가 만족스러우면 720p 등으로 높이는 것을 권장한다.
  • 생성 소요 시간: 생성 시간은 GPU 상황에 따라 다르며, 480p는 약 7분, 720p는 약 13분이 소요된다.

영상 생성 결과 확인

  • 2단계 처리 구조: 영상 제작은 1, 2단계를 거치며, 특히 2단계 화질 개선에서 시간이 오래 걸린다.
  • 결과 품질: 생성된 영상은 프롬프트대로 대사와 움직임이 잘 만들어졌음을 확인할 수 있다.
  • 결과물 저장: 결과물이 마음에 들면 다운로드 버튼을 눌러 저장한다.
  • 720p 제작 결과: 720p로 제작 시 시간이 걸리지만, 한국어 대사와 움직임이 자연스럽게 만들어진다.

영상 제작 팁 및 주의사항

영상 제작 팁

  • 시작/끝 이미지 활용 영상 제작: 시작 이미지와 끝 이미지를 넣어 나이가 들어가는 모습의 영상을 만들 수 있다.
    • 480p로 제작 시 약 58초가 소요되며, 젊은 여성이 나이가 들어가는 모습과 계절 변화가 자연스럽게 표현된다.
  • 고화질 영상 제작 권장: 720p로 제작하면 화질이 더 좋으므로, 다른 작업을 하면서 기다리는 것을 추천한다.

필수 주의사항

세션 종료

사용하지 않을 때는 반드시 '스톱 세션'을 눌러야 한다.

모델 삭제

세션을 종료하면 다운로드한 모델이 모두 사라지므로, 작업은 한 번에 몰아서 하는 것이 편리하다.

오류 해결

프로그램 셋업 오류 시 셀을 껐다 다시 실행하거나, 그라디오 화면 오류 시 링크를 재접속하면 대부분 해결된다.

결과물 저장

마음에 드는 결과물은 반드시 다운로드해야 모델과 함께 사라지지 않는다.

노트북 수정 및 저장

노트북 셀을 수정할 경우 '퀵 세이브'로 저장하고, '세이브 앤 런 올'은 전체 재실행되므로 주의한다.
